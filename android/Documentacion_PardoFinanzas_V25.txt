1. RESUMEN DE ARQUITECTURA Y TECNOLOGÍAS DE DESARROLLO
--------------------------------------------------------------------------------

1.1 Visión del Sistema y Filosofía de Software:
    PardoFinanzas V25 (Finanzas Pro) es una plataforma móvil de alto rendimiento diseñada para la gestión financiera personal de alta precisión. Su arquitectura combina un enfoque "Offline-First" con persistencia local ultrarrápida, analítica predictiva mediante Inteligencia Artificial y sincronización transparente con Google Sheets a través de webhooks de Google Apps Script.

1.2 Arquitectura del Sistema (Clean Architecture + MVVM + Android Architecture Components):
    El proyecto está estructurado rigurosamente bajo Clean Architecture y el patrón MVVM (Model-View-ViewModel), logrando un desacoplamiento total entre la lógica de interfaz, las reglas de negocio y las fuentes de datos.

    a) Capa de Presentación (UI Layer):
       - Construida al 100% en Jetpack Compose (Declarativa, sin XMLs de View).
       - Gestión de estado reactivo mediante StateFlow y SharedFlow scoped a ViewModels.
       - Arquitectura Unidireccional de Datos (UDF - Unidirectional Data Flow), garantizando que las pantallas rendericen estados inmutables (UI State) y envíen eventos de usuario de forma limpia.

    b) Capa de Dominio (Domain Layer):
       - Contiene la lógica de negocio pura, agnóstica de frameworks o librerías de Android.
       - Casos de Uso (Use Cases / Interactors) inyectados con Hilt/Dagger:
         * AddMovementUseCase: Procesa y valida nuevos registros de ingresos, gastos y transferencias, asignando IDs únicos con prefijo M- y agrupadores B-.
         * PayFixedExpenseUseCase: Gestiona el pago de cuotas recurrentes, actualizando el estado de la obligación, acumulando abonos e inyectando la etiqueta estructurada PAGO_FIJO|F-XXXX|MM-yyyy.
         * RollbackLastBatchUseCase: Ejecuta la reversión atómica del último grupo de registros insertados.
         * GenerateUniqueIdUseCase: Genera identificadores únicos alfanuméricos deterministas por estampa de tiempo y entropía.
         * GetDashboardStatusUseCase: Calcula consolidado de disponible real, alertas de sobregiro y deudas comprometidas.
       - Modelos de Dominio Puros: PardoMovement, PardoFixedExpense, BudgetAlert, DashboardStatus, FinancialNotification.

    c) Capa de Datos (Data Layer):
       - Implementación del patrón Repository para coordinar fuentes de datos locales y remotas.
       - Persistencia Local (Room DB): Base de datos SQLite empaquetada mediante Room Database (FinanceDatabase), con consultas optimizadas y transacciones atómicas (@Transaction).
         * TransactionDao: Gestión de la tabla 'transactions' con filtrado por perfil (profileId) y control de sincronización (isSynced).
         * FixedExpenseDao: Gestión de la tabla 'fixed_expenses'.
         * SavingsGoalDao: Gestión de la tabla 'savings_goals'.
       - Preferencias y Estado Ligero (DataStore Preferences): UserPreferencesRepository y SecurityRepository administrando tokens, perfiles, PIN de seguridad y URLs.
       - Cliente de Red y Sincronización Remota: OkHttpClient adaptado sin auto-redirección para capturar saltos 302/307 hacia script.googleusercontent.com preservando payloads POST JSON.

1.3 Stack Tecnológico y Lenguaje de Programación:
    - Lenguaje: Kotlin 2.x (100% idiomático, Corrutinas, Flujos asíncronos con Flow / StateFlow / SharedFlow).
    - Inyección de Dependencias: Hilt / Dagger (@HiltViewModel, @Singleton, @Inject).
    - Serialización de Datos: Kotlinx Serialization (Json configurado con ignoreUnknownKeys = true).
    - Persistencia Local: Room DB 2.6+ & DataStore Preferences.
    - Cliente HTTP: OkHttp3 con interceptor manual de redirecciones.
    - Inteligencia Artificial: Integración nativa con la API REST beta de Google Gemini (gemini-1.5-flash).

1.4 Interfaz de Usuario y Sistema de Diseño (Jetpack Compose Material 3 Expressive):
    - OLED Dark Theme: Paleta de color optimizada para pantallas AMOLED con fondo negro absoluto (#000000, Slate950/Slate900), minimizando el consumo de energía y ofreciendo un contraste visual profundo.
    - Glassmorphism UI: Componentes visuales translúcidos (GlassCard, GlassButton) con efecto de cristal esmerilado (Frosted Glass Blur), bordes suaves (GlassBorder) y gradientes dinámicos.
    - Física de Resortes (Spring Physics): Transiciones de pantalla y microinteracciones animadas con resortes elásticos (Modifier.bounceClick()), brindando una respuesta táctil orgánica.
    - Feedback Háptico (Haptics): Integración con LocalHapticFeedback (HapticFeedbackType.LongPress / TextHandleMove) que vibra sutilmente al presionar botones de 1-Tap, confirmar pagos de cuotas, ingresar PIN o superar el límite diario de gastos hormiga.
    - Soporte Edge-to-Edge: Renderizado de pantalla completa respetando insets del sistema (WindowInsets, Status Bar y Navigation Bar transparentes).

3. MAPEO TÉCNICO DE TABLAS GOOGLE SHEETS (14 Y 8 COLUMNAS)
--------------------------------------------------------------------------------

3.1 Tabla `MOVIMIENTOS` (14 Columnas Exactas):
    1. ID (String, ej. `M-20260905-8F31`): Identificador único de la transacción.
    2. Fecha (String, formato `YYYY-MM-DD`): Fecha de ejecución.
    3. Hora (String, formato `HH:mm:ss`): Hora exacta del registro.
    4. Tipo (String: `INGRESO`, `EGRESO`, `TRANSFERENCIA`, `NEUTRO`): Naturaleza del flujo.
    5. Categoría (String, ej. `Alimentación`, `Servicios`, `Ocio`): Categoría principal.
    6. Subcategoría (String, ej. `Restaurante`, `Gasto Hormiga`): Clasificación secundaria.
    7. Descripción / Concepto (String, ej. `Almuerzo`, `Pago Factura Luz`): Detalle del movimiento.
    8. Valor (Número Decimal / Entero): Monto de la operación.
    9. Método (String, ej. `Efectivo`, `Nequi`, `Bancolombia`, `Tarjeta`): Medio de pago.
    10. Cuenta (String, ej. `Nequi`, `Bancolombia`, `Efectivo`): Cuenta financiera afectada.
    11. Mes (String, ej. `Septiembre`): Mes del registro.
    12. Año (String, ej. `2026`): Año del registro.
    13. Origen (String: `"Android App"`, `"Telegram"`, `"Gmail"`): Canal origen del registro.
    14. Referencia / Tags (String): Etiquetas de trazabilidad estructuradas (ej. `PAGO_FIJO|F-1042|Septiembre 2026`, `ABONO_FIJO|...`, `CXC|...`, `|MOVIMIENTO_NEUTRO`, `GASTO_HORMIGA`).


3.2 Tabla `CONTROL FIJOS` (8 Columnas Exactas):
    1. ID (String, ej. `F-1042`): Identificador único de la obligación fija.
    2. Concepto (String, ej. `Arriendo Depto`, `Internet Fibra`): Nombre del compromiso.
    3. Categoría (String, ej. `Vivienda`, `Servicios`): Categoría del gasto.
    4. Día de cobro (Entero, 1 al 31): Día habitual del mes fijado para el pago.
    5. Valor mensual (Número Decimal): Cuota esperada del periodo.
    6. Último mes pagado (String, ej. `Septiembre 2026`): Periodo del último pago saldado.
    7. Fecha último pago (String, formato `YYYY-MM-DD`): Fecha exacta del último pago.
    8. Notas/Deuda (String): Observaciones adicionales o saldo acumulado.


3.3 Obras y Hojas Adicionales de la Plantilla Máster:
    - `PANEL`: Snapshot consolidado de Saldo Total, Disponible Real, Ingresos y Gastos.
    - `PRESUPUESTO Y ALERTAS`: Matriz de límites y estado de sobregiros por categoría.
    - `REGLAS COMERCIOS`: Inferencias automáticas de categoría por nombre de establecimiento.
    - `CUENTAS POR COBRAR`: Registro de deudas pendientes a favor.
    - `METAS AHORRO`: Registro de objetivos de ahorro y depósitos acumulados.


3.4 Generación Determinista de IDs Únicos:
    - Prefijo `M-`: Para transacciones en MOVIMIENTOS (ej. `M-20260905-A1B2`).
    - Prefijo `F-`: Para obligaciones en CONTROL FIJOS (ej. `F-1001`).
    - Prefijo `A-`: Para registros en METAS AHORRO (ej. `A-5001`).
    - Prefijo `B-`: Para identificadores de bloque transaccional (ej. `B-9988`).


3.5 Tratamiento de Transferencias Internas (Operaciones Neutras):
    - Las transferencias de dinero entre cuentas del mismo usuario (ej. Transferir de Bancolombia a Nequi) son clasificadas como `TRANSFERENCIA_INTERNA`.
    - No alteran el Patrimonio Neto ni el Saldo Total Consolidado, excluyéndose de los cálculos de Gastos o Ingresos del mes para evitar distorsionar la analítica.


3.6 Reversión Atómica por Bloque (`borrarUltimoConjunto`):
    - El caso de uso RollbackLastBatchUseCase ejecuta una transacción atómica local en Room DB para revertir el último grupo de transacciones (blockId).
    - Si el movimiento eliminado corresponde a un pago de cuota fija (`PAGO_FIJO|F-XXXX|MM-yyyy`), la aplicación restablece automáticamente el estado de la obligación en CONTROL FIJOS a `PENDIENTE`.
    - Transmite el comando 'borrar_ultimo' a Google Apps Script para eliminar la última fila en la hoja de cálculo.

4. SINCRONIZACIÓN INTELIGENTE DE GOOGLE APPS SCRIPT
--------------------------------------------------------------------------------

4.1 Aceptación Flexible de Entrada (ID Simple o URL Completa):
    - La aplicación acepta indistintamente un Script ID directo (ej. `AKfycb...`, longitud >= 20 caracteres) o una URL completa (`https://script.google.com/macros/s/.../exec` o `/edit`).
    - Función sanitizeUrl(): Elimina caracteres invisibles, espacios, comillas y caracteres de ancho cero (`\uFEFF`, `\u200B`, etc.).
    - Función extractScriptExecUrl(): Extrae la clave del script y construye de forma canónica la URL terminada en `/exec`.

4.2 Manejo Especializado de Redirecciones HTTP 302/307:
    - Problema Técnico de Google Apps Script: Al enviar peticiones HTTP POST a la Web App de Google, Google responde con un código de redirección HTTP 302/307 redirigiendo la petición a un servidor temporal en `script.googleusercontent.com`. Los clientes HTTP estándar convierten automáticamente la petición POST en un GET durante el salto 302, destruyendo el payload JSON.
    - Solución Implementada en GoogleDriveSyncRepositoryImpl: Se utiliza un cliente OkHttpClient con auto-redirección deshabilitada (followRedirects(false)). La app captura el código 302/307, extrae la cabecera 'Location', y reejecuta manualmente la solicitud HTTP POST preservando el cuerpo JSON codificado en UTF-8 hasta por 5 saltos.
    - Fallback de Respaldo: Si OkHttp falla, se ejecuta un algoritmo de contingencia mediante HttpURLConnection manteniendo la transmisión del flujo POST.

4.3 Arquitectura Offline-First (Room DB) y Auto-Sincronización:
    - La aplicación funciona al 100% sin conexión a internet utilizando la base de datos Room local.
    - Cada registro guardado en local posee la bandera isSynced = false.
    - Al recuperar la conectividad o presionar "Sincronizar ahora con Google Drive", syncAllDataToDrive() empaqueta todos los registros no sincronizados, transmite la carga batch a Google Apps Script y actualiza la bandera local a isSynced = true tras recibir respuesta exitosa HTTP 200.

4.4 Restauración Completa desde la Nube (`restoreDataFromDrive`):
    - Permite recuperar toda la información guardada en Google Sheets tras un cambio de dispositivo o reinstalación.
    - Envía una petición GET con el parámetro `?accion=restaurar`, parsea el JSON con movimientos, fijos y metas, limpian las tablas locales del perfil e insertan en lote los registros restaurados.

```javascript
/**
 * ============================================================================
 * GOOGLE APPS SCRIPT V25.3 PRO REST - PARDOFINANZAS / FINANZAS PRO (2026)
 * ============================================================================
 * Edición con Extensión REST API (doGet y doPost) para sincronización con
 * Android App, Telegram Bot, Gmail Parser y Google Sheets.
 */

const HOJA_MOVIMIENTOS = "MOVIMIENTOS";
const HOJA_CONTROL_FIJOS = "CONTROL FIJOS";
const HOJA_PANEL = "PANEL";
const HOJA_PRESUPUESTO = "PRESUPUESTO Y ALERTAS";
const HOJA_REGLAS = "REGLAS COMERCIOS";
const HOJA_CXC = "CUENTAS POR COBRAR";
const HOJA_METAS = "METAS AHORRO";
const EXCLUIR_CUENTA = "Clara Aide";

function doGet(e) {
  try {
    const params = (e && e.parameter) ? e.parameter : {};
    const accion = params.accion || "resumen";
    const ss = SpreadsheetApp.getActiveSpreadsheet();

    switch (accion) {
      case "resumen": return jsonResponse(obtenerResumenFinanciero(ss));
      case "movimientos": return jsonResponse(obtenerListaMovimientos(ss));
      case "fijos": return jsonResponse(obtenerListaGastosFijos(ss));
      case "disponible": return jsonResponse(obtenerDisponibleReal(ss));
      case "fugas": return jsonResponse(obtenerGastosHormigaFugas(ss));
      case "restaurar": return jsonResponse(obtenerDatosCompletosRestauracion(ss));
      default:
        return jsonResponse({ status: "ok", message: "Google Apps Script V25.3 PRO REST activo" });
    }
  } catch (err) {
    return jsonResponse({ status: "error", message: err.toString() });
  }
}

function doPost(e) {
  try {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    let body = {};
    if (e && e.postData && e.postData.contents) {
      body = JSON.parse(e.postData.contents);
    }
    const params = (e && e.parameter) ? e.parameter : {};
    const accion = body.accion || body.action || params.accion || "sync";

    switch (accion) {
      case "nuevo_movimiento": return jsonResponse(registrarNuevoMovimiento(ss, body));
      case "pagar_fijo": return jsonResponse(registrarPagoGastoFijo(ss, body));
      case "borrar_ultimo": return jsonResponse(borrarUltimoConjunto(ss));
      case "sync":
      default: return jsonResponse(procesarSincronizacionCompleta(ss, body));
    }
  } catch (err) {
    return jsonResponse({ status: "error", message: err.toString() });
  }
}

function obtenerResumenFinanciero(ss) {
  const sheetMov = getOrCreateSheet(ss, HOJA_MOVIMIENTOS);
  const rows = sheetMov.getDataRange().getValues();
  let totalIngresos = 0, totalGastos = 0;

  for (let i = 1; i < rows.length; i++) {
    const row = rows[i];
    if (!row[0]) continue;
    const tipo = String(row[3] || "").toUpperCase();
    const cuenta = String(row[9] || "");
    const valor = Number(row[7]) || 0;
    if (cuenta.includes(EXCLUIR_CUENTA)) continue;
    if (tipo === "INGRESO") totalIngresos += valor;
    else if (tipo === "EGRESO" || tipo === "GASTO") totalGastos += valor;
  }
  return { balance: totalIngresos - totalGastos, disponible: obtenerDisponibleRealMonto(ss), ingresos: totalIngresos, gastos: totalGastos };
}

function obtenerListaMovimientos(ss) {
  const sheetMov = getOrCreateSheet(ss, HOJA_MOVIMIENTOS);
  const rows = sheetMov.getDataRange().getValues();
  const resultado = [];
  for (let i = 1; i < rows.length; i++) {
    const r = rows[i];
    if (!r[0]) continue;
    if (String(r[9] || "").includes(EXCLUIR_CUENTA)) continue;
    resultado.push({
      id: String(r[0]), fecha: formatFecha(r[1]), hora: String(r[2] || ""), tipo: String(r[3] || "EGRESO"),
      categoria: String(r[4] || ""), subcategoria: String(r[5] || ""), descripcion: String(r[6] || ""),
      valor: Number(r[7]) || 0, metodo: String(r[8] || ""), cuenta: String(r[9] || ""),
      mes: String(r[10] || ""), ano: String(r[11] || ""), origen: String(r[12] || "Android App"), referencia: String(r[13] || "")
    });
  }
  return resultado;
}

function obtenerListaGastosFijos(ss) {
  const sheetFijos = getOrCreateSheet(ss, HOJA_CONTROL_FIJOS);

  return resultado;
}

function obtenerDatosCompletosRestauracion(ss) {
  const movs = obtenerListaMovimientos(ss);
  const fijos = obtenerListaGastosFijos(ss);

  const sheetMetas = getOrCreateSheet(ss, HOJA_METAS);
  const rowsMetas = sheetMetas.getDataRange().getValues();
  const metas = [];
  for (let i = 1; i < rowsMetas.length; i++) {
    const r = rowsMetas[i]; if (!r[0]) continue;
    metas.push({
      id: Number(r[0]) || i,
      name: String(r[1] || "Meta"),
      targetAmount: Number(r[2]) || 0,
      currentAmount: Number(r[3]) || 0,
      category: String(r[4] || "General")
    });
  }

  return {
    status: "success",
    movimientos: movs.map(m => ({
      id: m.id, fecha: m.fecha, concepto: m.descripcion || m.concepto || "",
      monto: m.valor, tipo: m.tipo.toLowerCase(), categoria: m.categoria, cuenta: m.cuenta, observaciones: m.referencia
    })),
    gastosFijos: fijos.map(f => ({
      id: parseInt(f.id.replace("F-", "")) || 1, concepto: f.concepto, monto: f.valorMensual, diaPago: f.diaCobro
    })),
    metasAhorro: metas
  };
}

function obtenerDisponibleRealMonto(ss) {
  const res = obtenerResumenFinancieroPuro(ss);
  const fijos = obtenerListaGastosFijos(ss);
  const now = new Date();
  const mesAno = getMesNombre(now.getMonth()) + " " + now.getFullYear();
  let comp = 0;
  fijos.forEach(f => { if (f.ultimoMesPagado !== mesAno) comp += f.valorMensual; });
  return Math.max(0, res.balance - comp);
}

function obtenerDisponibleReal(ss) {
  return { disponibleReal: obtenerDisponibleRealMonto(ss), fechaConsulta: new Date().toISOString() };
}

function obtenerGastosHormigaFugas(ss) {
  const sheetMov = getOrCreateSheet(ss, HOJA_MOVIMIENTOS);
  const rows = sheetMov.getDataRange().getValues();
  let total = 0; const detalles = [];
  for (let i = 1; i < rows.length; i++) {
    const r = rows[i]; if (!r[0]) continue;
    const cat = String(r[4] || "").toLowerCase();
    const ref = String(r[13] || "").toLowerCase();
    if (cat.includes("hormiga") || ref.includes("gasto_hormiga")) {

}

function registrarNuevoMovimiento(ss, data) {
  const sheetMov = getOrCreateSheet(ss, HOJA_MOVIMIENTOS);
  const m = data.movimiento || data;
  const now = new Date();
  const idStr = m.id || "M-" + now.getTime();
  sheetMov.appendRow([
    idStr, m.fecha || now.toISOString().split('T')[0], m.hora || now.toTimeString().split(' ')[0],
    m.tipo || "EGRESO", m.categoria || "General", m.subcategoria || "", m.descripcion || m.concepto || "",
    Number(m.valor || m.monto) || 0, m.metodo || "Efectivo", m.cuenta || "Efectivo",
    m.mes || getMesNombre(now.getMonth()), m.ano || String(now.getFullYear()), "Android App", m.referencia || m.observaciones || ""
  ]);
  return { success: true, message: "Movimiento registrado", id: idStr };
}

function registrarPagoGastoFijo(ss, data) {
  const sheetFijos = getOrCreateSheet(ss, HOJA_CONTROL_FIJOS);
  const rows = sheetFijos.getDataRange().getValues();
  const idFijo = data.idFijo || data.id;
  const now = new Date();
  const mesAno = data.periodo || (getMesNombre(now.getMonth()) + " " + now.getFullYear());
  const fechaHoy = now.toISOString().split('T')[0];
  let encontrado = false, concepto = "Gasto Fijo", valor = Number(data.monto) || 0;
  for (let i = 1; i < rows.length; i++) {
    if (String(rows[i][0]) === String(idFijo)) {
      concepto = String(rows[i][1]); if (valor === 0) valor = Number(rows[i][4]) || 0;
      sheetFijos.getRange(i + 1, 6).setValue(mesAno);
      sheetFijos.getRange(i + 1, 7).setValue(fechaHoy);
      encontrado = true; break;
    }
  }
  const tagRef = "PAGO_FIJO|" + idFijo + "|" + mesAno;
  registrarNuevoMovimiento(ss, {
    id: "M-" + now.getTime(), fecha: fechaHoy, hora: now.toTimeString().split(' ')[0], tipo: "EGRESO",
    categoria: "Servicios/Fijos", descripcion: "Pago Cuota: " + concepto, valor: valor,
    metodo: data.metodoPago || "Nequi", cuenta: data.cuenta || "Nequi", origen: "Android App", referencia: tagRef
  });
  return { success: true, message: "Pago registrado", idFijo: idFijo, tag: tagRef };
}

function borrarUltimoConjunto(ss) {
  const sheetMov = getOrCreateSheet(ss, HOJA_MOVIMIENTOS);
  const lastRow = sheetMov.getLastRow();
  if (lastRow <= 1) return { success: false, message: "No hay movimientos" };
  const values = sheetMov.getRange(lastRow, 1, 1, 14).getValues()[0];
  const ref = String(values[13] || "");
  if (ref.startsWith("PAGO_FIJO|")) {
    const p = ref.split("|"); if (p.length >= 2) revertirEstadoGastoFijo(ss, p[1]);
  }
  sheetMov.deleteRow(lastRow);
  return { success: true, message: "Último movimiento eliminado", idEliminado: values[0] };
}

function revertirEstadoGastoFijo(ss, idFijo) {
  const sheetFijos = getOrCreateSheet(ss, HOJA_CONTROL_FIJOS);
  const rows = sheetFijos.getDataRange().getValues();
  for (let i = 1; i < rows.length; i++) {
    if (String(rows[i][0]) === String(idFijo)) {
      sheetFijos.getRange(i + 1, 6).setValue("");
      sheetFijos.getRange(i + 1, 7).setValue("");
      break;
    }
  }
}

function procesarSincronizacionCompleta(ss, data) {
  if (data.movimientos && Array.isArray(data.movimientos)) {
    const sheetMov = getOrCreateSheet(ss, HOJA_MOVIMIENTOS);
    sheetMov.clearContents();
    sheetMov.appendRow(["ID", "Fecha", "Hora", "Tipo", "Categoría", "Subcategoría", "Descripción", "Valor", "Método", "Cuenta", "Mes", "Año", "Origen", "Referencia"]);
    data.movimientos.forEach(m => {
      sheetMov.appendRow([
        m.id || "", m.fecha || "", m.hora || "", m.tipo || "EGRESO", m.categoria || "", m.subcategoria || "",
        m.descripcion || m.concepto || "", Number(m.valor || m.monto) || 0, m.metodo || "", m.cuenta || "Efectivo",
        m.mes || "", m.ano || "", "Android App", m.referencia || m.observaciones || ""
      ]);
    });
  }
  if (data.gastosFijos && Array.isArray(data.gastosFijos)) {
    const sheetFijos = getOrCreateSheet(ss, HOJA_CONTROL_FIJOS);
    sheetFijos.clearContents();
    sheetFijos.appendRow(["ID", "Concepto", "Categoría", "Día de cobro", "Valor mensual", "Último mes pagado", "Fecha último pago", "Notas/Deuda"]);
    data.gastosFijos.forEach(f => {
      sheetFijos.appendRow([
        f.id || "", f.concepto || "", f.categoria || "", Number(f.diaCobro || f.diaPago) || 1,
        Number(f.valorMensual || f.monto) || 0, f.ultimoMesPagado || "", f.fechaUltimoPago || "", f.notasDeuda || ""
      ]);
    });
  }
  if (data.metasAhorro && Array.isArray(data.metasAhorro)) {
    const sheetMetas = getOrCreateSheet(ss, HOJA_METAS);
    sheetMetas.clearContents();
    sheetMetas.appendRow(["ID", "Nombre", "MontoObjetivo", "MontoActual", "Categoría"]);
    data.metasAhorro.forEach(g => {
      sheetMetas.appendRow([g.id, g.name, g.targetAmount, g.currentAmount, g.category || 'General']);
    });
  }
  return { status: "success", message: "Sincronización exitosa", syncedCount: data.movimientos ? data.movimientos.length : 0 };
}

function obtenerResumenFinancieroPuro(ss) {
  const sheetMov = getOrCreateSheet(ss, HOJA_MOVIMIENTOS);
  const rows = sheetMov.getDataRange().getValues();
  let ing = 0, gas = 0;
  for (let i = 1; i < rows.length; i++) {
    const r = rows[i]; if (!r[0] || String(r[9] || "").includes(EXCLUIR_CUENTA)) continue;
    const t = String(r[3] || "").toUpperCase(), v = Number(r[7]) || 0;
    if (t === "INGRESO") ing += v; else if (t === "EGRESO" || t === "GASTO") gas += v;
  }
  return { balance: ing - gas, ingresos: ing, gastos: gas };
}

function getOrCreateSheet(ss, name) {
  let sheet = ss.getSheetByName(name);
  if (!sheet) sheet = ss.insertSheet(name);
  return sheet;
}

function jsonResponse(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj)).setMimeType(ContentService.MimeType.JSON);
}

function formatFecha(val) {
  if (!val) return "";
  if (val instanceof Date) return val.toISOString().split('T')[0];
  return String(val);
}

function getMesNombre(mesIdx) {
  const meses = ["Enero", "Febrero", "Marzo", "Abril", "Mayo", "Junio", "Julio", "Agosto", "Septiembre", "Octubre", "Noviembre", "Diciembre"];
  return meses[mesIdx] || "Enero";
}
```
